\begin{abstract}
We study a compact action-conditioned dynamics model trained from robot manipulation trajectories. Rather than beginning with an unconstrained toy environment, we use the NVIDIA PhysicalAI-Robotics-Manipulation-SingleArm collection, which provides Franka Panda state, action, RGB, and depth observations across procedurally varied tabletop tasks. Our first benchmark deliberately excludes video and predicts the next robot state from the current state and action. We measure one-step error, multi-step rollout error, and scaling with the number of demonstration transitions. This establishes a reproducible small-compute baseline before adding visual prediction and model-based control.
\end{abstract}

\section{Introduction}
World models provide a way to reuse expensive robot interaction by predicting how actions change future states. The goal of this project is not to claim a general robot foundation model, but to make the complete experimental loop transparent: ingest robot demonstrations, learn action-conditioned dynamics, evaluate predictive accuracy, and eventually plan through the learned model.

\section{Dataset}
We use NVIDIA's \href{https://huggingface.co/datasets/nvidia/PhysicalAI-Robotics-Manipulation-SingleArm}{PhysicalAI-Robotics-Manipulation-SingleArm} dataset. The dataset contains six Franka Panda tasks: block stacking, platform stacking, texture-randomized stacking, left/right cabinet opening, and drawer opening. The release is generated in Isaac Sim using task-and-motion planning and procedurally varied tabletop scenes. It contains approximately 15.2~GB, more than 38,000 episodes across the subsets, 53- or 81-dimensional state, and 7- or 8-dimensional actions. State includes robot proprioception, end-effector pose, and object poses; camera subsets provide 512$\times$512 RGB and, for selected tasks, depth observations.

The first experiment downloads only Parquet state/action files and metadata. Video is reserved for the visual world-model extension. We split by episode rather than by adjacent frames to prevent temporal leakage.

\section{Method}
For each episode, we construct transitions $(s_t,a_t,s_{t+1})$ only when consecutive frames belong to the same episode. A small MLP predicts
\begin{equation}
    \hat{s}_{t+1}=f_\theta(s_t,a_t).
\end{equation}
The baseline objective is mean-squared next-state error. We will compare absolute-state prediction against normalized residual prediction, $\Delta s_t=s_{t+1}-s_t$, because residual targets may be easier for mostly-smooth robot trajectories.

For model-based control, we expose the learned predictor as a goal-conditioned Gymnasium environment. Initial states and goals are sampled from held-out demonstration episodes, while all intermediate transitions are generated by $f_\theta$. This enables offline/model-based RL experiments without confusing dataset replay with physical interaction.

\section{Benchmark Protocol}
We report validation one-step MSE, per-dimension normalized MSE, and multi-step rollout error for horizons 1, 5, and 10. Experiments vary the number of training transitions (1\%, 5\%, 10\%, 25\%, and 100\%), task subset, random seed, model width, and preprocessing variant. The final control experiment will compare behavior cloning, model-predictive control through the learned model, and a model-free baseline in a replayable simulator.

The first bounded run uses ten \texttt{panda-stack-wide} episodes (611 training transitions and 76 validation transitions) and 300 optimizer updates. The absolute-state baseline achieved validation MSE $0.0496$; the normalized residual variant achieved $0.962$ in normalized target units. These values are preliminary and are not directly comparable across target parameterizations without reporting physical-unit errors. The benchmark script records absolute raw, absolute normalized, and residual normalized variants under a common protocol. The 100-episode scaling sweep is generated by \texttt{scripts/run\_data\_scaling.py}.

The larger sweep uses 10, 25, 50, and 100 episodes with 500 updates per variant. Absolute raw validation MSEs were 0.0407, 0.0265, 0.0222, and 0.0220, respectively. The corresponding normalized-absolute values were 0.6535, 0.2029, 0.1361, and 0.1398. The residual-normalized values were 1.0150, 0.9906, 0.3537, and 0.3706. The raw-state curve provides the first evidence of improved prediction with more robot demonstrations; larger seeds and physical-unit normalization are required before interpreting the preprocessing ranking.

Using the 100-episode raw model, teacher-forced model rollouts had MSE 0.0127, 0.0329, and 0.0868 at horizons 1, 5, and 10. The compounding error motivates evaluating model-based control separately from one-step prediction.

In a preliminary learned-simulator comparison on five episodes and ten model steps, mean dense goal-progress returns were $-0.0914$ for random actions, $-0.0561$ for goal-conditioned behavior cloning, and $-0.0277$ for CEM planning. All three methods had zero sparse successes in this short evaluation. These results indicate a useful planning signal, but not yet reliable task completion.

After adding the Panda stacking-specific metric, a three-episode smoke test at ten model steps produced returns of $-0.5276$ for random actions, $-0.5322$ for behavior cloning, and $0.0292$ for CEM. The stacking success criterion is horizontal box separation below 6~cm and vertical gap between 3 and 9~cm. CEM's positive dense progress is encouraging, but sparse success remained zero.

\section{Limitations}
The initial SingleArm data are synthetic Isaac Sim trajectories rather than physical robot recordings. Offline prediction accuracy does not automatically imply closed-loop control quality. The project therefore treats visual prediction, simulator replay, real-data transfer, and a PPO/SAC comparison as separate milestones rather than conflating them with the first supervised result.

\section{Reproducibility}
The code, configuration, data download command, random seeds, and output metrics are maintained in the accompanying repository. The first state-only run can be launched with:
\begin{verbatim}
python scripts/download_single_arm.py --output data/single_arm
python scripts/train_real_world_model.py data/single_arm --steps 2000
\end{verbatim}
